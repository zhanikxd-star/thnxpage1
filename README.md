# impact admissions — запись на консультацию

Посадочная страница воронки: бесплатная консультация Impact. Тексты и факты взяты с публичного сайта [impact-admissions.com](https://impact-admissions.com/). Чего на сайте нет, на странице оставлено плейсхолдером и помечено в комментариях к коду.

В слоте ролика пока стоит чужое видео как пример плеера. Шкала не перематывается. Речь основателя по-прежнему не опубликована.

```bash
npm install
npm run dev
```

Открыть http://localhost:5173/

Сборка: `npm run build`, затем `npm run preview` (http://localhost:4173/).
