# thnxpage1

Thank-you page for [impact admissions](https://impact-admissions.com/), shown right after a family submits a request for the free admissions review.

The page is in Russian, like the live site. It confirms the request, says what happens next, and explains what the call covers. It does not ask for the lead again.

## Open locally

```bash
npm install
npm run dev
```

Vite prints a local URL, usually http://localhost:5173.

```bash
npm run build
npm run preview
```

The page is `index.html`.
